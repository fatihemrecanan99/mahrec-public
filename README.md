# Mahrec — public files

This repository holds only the public files of the Mahrec app. The app's source code is not here.

- **Recitation model** (`ggml-mahrec-q8_0.bin`, in Releases): an 8-bit quantised ggml conversion of
  [tarteel-ai/whisper-base-ar-quran](https://huggingface.co/tarteel-ai/whisper-base-ar-quran), licensed under the
  Apache License 2.0 (see `LICENSE-MODEL.txt`). Changes: converted from Hugging Face format to ggml with whisper.cpp
  and quantised to q8_0. No retraining.
- **Privacy policy**: https://fatihemrecanan99.github.io/mahrec-public/gizlilik/
